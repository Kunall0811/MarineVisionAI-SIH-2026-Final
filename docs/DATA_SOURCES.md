# Historical data sources

The globe's historical layer is stored in MongoDB and is clearly marked as `HISTORICAL_REFERENCE`.

Key sources used by the seed data:

- NOAA Titanic expedition / wreck references:
  https://repository.library.noaa.gov/view/noaa/10519/noaa_10519_DS1.pdf
- NOAA Titanic Ocean Today:
  https://oceantoday.noaa.gov/titanicwrecksite/
- NOAA IncidentNews — Maersk Essen:
  https://incidentnews.noaa.gov/incident/10221
- NOAA IncidentNews — Washington Coast containers:
  https://incidentnews.noaa.gov/incident/10374
- NOAA IncidentNews — M/V Tourist No. 2:
  https://incidentnews.noaa.gov/incident/10496
- NOAA IncidentNews — F/V Matador:
  https://incidentnews.noaa.gov/incident/10567
- NOAA IncidentNews — Tug MAZAPETA:
  https://incidentnews.noaa.gov/incident/10669
- NOAA IncidentNews — President Eisenhower containers:
  https://incidentnews.noaa.gov/incident/10740
- NOAA IncidentNews — DALI / Key Bridge:
  https://incidentnews.noaa.gov/incident/10761
- NOAA IncidentNews — S.M. Portland:
  https://incidentnews.noaa.gov/incident/10930
- NOAA Marine Debris Program — derelict fishing gear:
  https://marinedebris.noaa.gov/what-marine-debris/derelict-fishing-gear
- NOAA Marine Debris Program — Upper Great Lakes ghost nets:
  https://marinedebris.noaa.gov/removal/increasing-efficiency-locating-and-removing-ghost-nets-upper-great-lakes

The 2021–2025 layer is a curated reference collection, not a complete census of all global marine debris. Coordinates are marked approximate where the source reports approximate incident locations.
